# GAS ( Google ActionScript )

個人的に作成した Google Workspace用の GAS をまとめたディレクトリ

## `trashOldMail.gs`

Gmailで受信したメールを次の条件で自動でゴミ箱に移動するGASです。

**【重要】**

- 条件をよく確認して利用してください
- 自己責任で利用してください

**【免責事項】**

- 本コードの利用により、残しておきたかったメールや必要なメールが削除された場合でも、作成者は一切の責任を負いません
- 本コードの利用によって生じたいかなる損害・不利益についても、作成者は責任を負いかねます
- 必ず `DRY_RUN` で対象メールを確認したうえで、ご自身の判断と責任のもとで利用してください

|function|機能|
|--|--|
| `trashOldThreads` | 条件にしたがってメールをゴミ箱に移動する |
| `setupMonthlyTrigger` | `trashOldThreads` を指定日時に実行するトリガーを設定する |

### 条件

- 削除対象
  - 受信日が3年以上前のメール
- 対象から除外
  - メールスレッドの最新が3年未満
  - スター付き

※ 重要マークのメールは削除対象にしています。なぜなら、Gmail側の自動判定で付与されることがあるためで、たとえばチケット予約の完了メールなどに自動付与されることがあります。これらの3年以上前のメールを残す必要性がないため、対象にしています。

### 実行日時、実行時間

- 毎月1日午前3時ごろに実行
- GAS の6分制限内に自動で実行終了

### 設定前の事前準備

あらかじめ本コードを設定する前に、次の手順で3年以上前のメールを手動削除しておいてください。たとえば対象メールが数千件など大量にある場合、上記の GAS の6分間制限のルールに引っかかる可能性があるためです。

1. Gmailを開く
2. 検索ウィンドウに「 older_than:3y 」を入力して検索。受信日が3年以上前のメールが検索結果として表示されます
3. メールリスト、左上のチェックボックスをチェック
4. 「この検索条件に一致するすべてのメッセージを選択」のリンクを押下
5. ゴミ箱に移動するのを実行

### 使い方

デバッグ時など初回実行時に、アクセス承認を確認されるので、画面の案内にしたがって承認してください。
承認をキャンセルすると自動処理が実行されません。

1. [script.google.com](script.google.com) にアクセス
2. 新規プロジェクトを作成（プロジェクト名などはお好みでOKです）
3. ファイル「+」を押下し、新規GASファイルを追加
4. 上記コードをコピペで貼り付け
5. メニュー部分に、ファイル内にある function が、プルダウンメニューで表示されていることを確認する
6. `trashOldThreads` がプルダウンメニューに選択されている状態で 「デバッグ」を実行、動作確認する
7. コード内の、DRY_RUN の値を `true` から `false` に変更
8. メニューのプルダウンを確認、 `trashOldThreads` と `setupMonthlyTrigger` をそれぞれ実行する
9. サイドメニューにある「トリガー（時計アイコン）」を確認、 `setupMonthlyTrigger` が登録されていることを確認
10. 設定完了
