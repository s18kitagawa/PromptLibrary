# ストックフォト出品用 写真スクリーニング依頼

## 目的
ローカルに保存しているRAW写真データの中から、ストックフォトサービスへの出品候補となる写真を一次選定する。
人物の顔が識別できる写真は権利上のリスクがあるため、選定対象から除外する。

## 対象フォルダ
- RAW格納フォルダ（入力）：`（ここに対象フォルダのパスを記入）`
- 出力先フォルダ（作業用）：`~/Pictures/StockUpload`

※ 出力（プレビューJPEGや振り分けフォルダ）はRAW格納フォルダの配下ではなく、`~/Pictures/StockUpload` 配下に作成すること。RAW格納フォルダ配下に生成すると、Lightroomなど現像ソフトの読み込み対象に含まれてしまうため。

## 全体の流れ（1タスクとして通しで実行してほしい）

1. 対象フォルダ内のRAWファイル（CR2 / NEF / ARW など）を検出する
2. 各RAWファイルから内蔵プレビューJPEGを抽出する（ExifToolの `-PreviewImage` 等、高速な方法を優先）
3. 抽出したプレビューJPEGに対して顔検出処理を実行する（OpenCVのHaar Cascade、mediapipe Face Detectionなど軽量なライブラリでよい）
4. 判定結果に応じて振り分ける
   - 顔が検出された写真 → `要確認` フォルダへ移動
   - 顔が検出されなかった写真 → `一次選定対象` フォルダへ移動
5. `一次選定対象` フォルダ内のプレビューJPEGを確認し、構図・明るさ・色味・被写体の魅力などの観点で一次選定を行う
6. 一次選定の結果（候補一覧、簡単な選定理由、除外理由）をまとめて報告する

## フォルダ構成（出力イメージ）

```
（RAW格納フォルダ）/
└── 元のRAWファイル群 ※このフォルダの中には何も生成しない

~/Pictures/StockUpload/
├── preview_jpeg/        ← 抽出したプレビューJPEG一式
├── 要確認/               ← 顔検出でヒットしたもの
└── 一次選定対象/          ← 顔検出をパスし、一次選定にかけるもの
```

## 一次選定の観点
- 構図のバランス
- 明るさ・色味の印象
- 被写体としての魅力・訴求力
- ピント感（プレビュー画質でわかる範囲でよい）

## 明示しておきたい制約・注意事項
- 判定はあくまで一次スクリーニングであり、最終判断ではない
- 顔検出は完全ではないため、誤検出・見逃しが起こり得る前提で運用する
- ピクセル等倍レベルの微細な技術チェック（ノイズ、色収差、圧縮ノイズなど）は対象外でよい
- 処理はまず小規模フォルダ（10〜20枚程度）で試し、精度を確認してからスケールする

## 依頼時に伝えること（テンプレート）
> 「〇〇フォルダ内のRAWファイルからプレビューJPEGを抽出してください。抽出先や振り分け先は〇〇フォルダの配下ではなく、`~/Pictures/StockUpload` フォルダの配下（preview_jpeg／要確認／一次選定対象）に作成してください。顔検出で人物の顔が写っている写真は『要確認』フォルダに振り分け、顔が検出されなかった写真は『一次選定対象』フォルダに入れたうえで、構図・明るさ・色味・被写体の魅力の観点で一次選定を行い、候補と簡単な選定理由をまとめて報告してください。」

## 今後の運用（繰り返し利用する場合）
- 上記の変換・顔検出・振り分け処理をスクリプトとして保存し、次回以降はフォルダ指定のみで再利用できるようにする
- 一次選定を通過した候補のみ、Lightroom等で本格現像し、出品先サービスの規定に合わせた高解像度JPEGに仕上げる
